# סוכן "כל מה שמעניין בבריאות" 🩺

סוכן אוטומטי שרץ ב-GitHub Actions, **אחת לשבועיים ביום ראשון בבוקר**, אוסף
כתבות טריות ממקורות בריאות/תזונה/לונג'ביטי מובילים, כותב **סיכום קצר בעברית**
לכל אחת, ושולח לך **6 כתבות למייל** בעיצוב נקי. הסוכן **זוכר מה כבר שלח**
ולעולם לא חוזר על אותה כתבה.

## התקנה — 5 שלבים

### 1. העלה את הקבצים ל-repo חדש בגיטהאב
צור repo (יכול להיות פרטי) והעלה אליו את כל התיקייה **כמו שהיא**, כולל
הנתיב `.github/workflows/`.

### 2. הפק סיסמת אפליקציה ל-Gmail
כמו שעשינו בעבר:
1. `myaccount.google.com` ← **אבטחה** ← ודא ש**אימות דו-שלבי** מופעל.
2. חפש **App Passwords / סיסמאות אפליקציה** ← צור חדשה, קרא לה `health-digest`.
3. תקבל סיסמה בת 16 תווים (4 קבוצות של 4). שמור אותה לרגע.

### 3. הזן את הסודות ב-GitHub
ב-repo: **Settings ← Secrets and variables ← Actions ← New repository secret**.
צור את ארבעת הסודות הבאים:

| שם הסוד | ערך |
|----------|-----|
| `GMAIL_ADDRESS` | כתובת ה-Gmail שממנה נשלח (למשל `you@gmail.com`) |
| `GMAIL_APP_PASSWORD` | 16 התווים מהשלב הקודם (אפשר עם או בלי רווחים) |
| `RECIPIENT` | לאן לשלוח. אם תשמיט — נשלח לאותה כתובת Gmail |
| `ANTHROPIC_API_KEY` | מפתח ה-API שלך מ-`console.anthropic.com` (לסיכומים) |

### 4. תן ל-Actions הרשאת כתיבה (כדי שיוכל לעדכן את `seen.json`)
**Settings ← Actions ← General ← Workflow permissions ← Read and write permissions ← Save.**

### 5. הרצת בדיקה ראשונה (עכשיו, בלי לחכות ליום ראשון)
**Actions ← "Health & Longevity Digest" ← Run workflow** ← השאר `force = true` ← **Run**.
תוך דקה-שתיים אמור להגיע מייל עם 6 כתבות. ✅

## איך זה עובד (בקצרה)

- **תזמון:** GitHub לא יודע "כל שבועיים", אז ה-workflow רץ **כל** יום ראשון
  ב-05:00 UTC (≈ 08:00 קיץ / 07:00 חורף בישראל), והסקריפט עצמו מחליט לפעול
  רק ב**שבועות זוגיים** (לפי מספר השבוע בשנה). הרצה ידנית תמיד עוברת.
- **מקורות:** רשימת ה-feeds נמצאת בראש `digest.py` במשתנה `FEEDS`.
- **טקסט מלא:** הסוכן מעדיף את גוף הכתבה המלא מה-feed. אם feed מסוים נשבר,
  הוא **מגלה את כתובת ה-feed לבד** מדף הבית, ואם גם זה נכשל — פשוט מדלג עליו
  בלי להפיל את כל הריצה.
- **דדופ:** כל קישור נשמר ב-`seen.json` (מנוקה מפרמטרי מעקב), וכתבה שכבר
  נשלחה לא תישלח שוב. הקובץ מוגבל ל-2000 קישורים אחרונים.
- **בחירת ה-6:** כל הכתבות החדשות שלא נשלחו, ממוינות מהחדשה לישנה, 6 הראשונות.
- **בטיחות:** המייל נשלח קודם; רק אחרי שליחה מוצלחת מסומנות הכתבות כ"נשלחו",
  כך שתקלה לא "שורפת" כתבות.

## שינויים נפוצים

- **להוסיף/להסיר אתר:** ערוך את `FEEDS` בראש `digest.py`.
- **לשנות כמות כתבות:** משתנה `ARTICLES_PER_RUN` (ברירת מחדל 6), או Secret בשם
  `ARTICLES_PER_RUN`.
- **גיוון מקורות:** `MAX_PER_SOURCE` (ברירת מחדל 2) — מקסימום כתבות מאותו אתר
  במקבץ אחד, כדי שאתר פורה (כמו Fight Aging!) לא ימלא את כל המייל. `0` = בלי הגבלה.
- **טקסט מלא:** אם feed נותן רק תקציר קצר, הסוכן מושך את דף הכתבה וקורא את הגוף
  המלא לפני הסיכום. הסף נשלט ע"י `MIN_FULLTEXT_CHARS` (ברירת מחדל 600 תווים).
- **לשנות שעה:** ערוך את שורת ה-`cron` ב-`health-digest.yml` (בזמן UTC).
- **שבוע זוגי/אי-זוגי:** אם הריצה הראשונה נופלת על שבוע "לא נכון", הוסף Secret
  `EVEN_WEEKS=false`, או פשוט חכה שבוע.
- **מודל הסיכום:** ברירת המחדל `claude-sonnet-5`. אפשר לשנות ל-Haiku (זול יותר)
  דרך Secret `ANTHROPIC_MODEL`.

## הערה על מקורות ה-RSS

כתובות ה-feed שבקוד הן הנפוצות והנכונות ביותר נכון להקמה, והסוכן יודע לתקן
לבד feed שנשבר (גילוי אוטומטי מדף הבית). אם בכל זאת אתר מסוים מפסיק להופיע
בלוגים (`0 items`), פתח את כתובת ה-feed שלו בדפדפן — אם רואים קוד XML היא
תקינה, אם רואים דף רגיל צריך כתובת אחרת. זה בדיוק אותו טריק אימות מהעבר.

## הערה על חוקיות

הסוכן **לא משכפל** תוכן מוגן: הוא מנסח סיכום מקורי משלו בעברית ותמיד מקשר
למקור. חלק מהמקורות (Fight Aging!, The Conversation, NIA) ברישוי Creative
Commons / נחלת הכלל ממילא.
